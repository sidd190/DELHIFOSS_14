# Web assets and editorial context

No generated images are used in this edition. The NVIDIA panel is a fictional meme, not a real quote or an allegation that a particular individual committed espionage. The APT icon is a generic fictional actor. Dragon sizes are a visual joke, not a comparative effectiveness result.

- Jensen Huang portrait: Peter Dasilva / European Commission, [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Jensen_Huang_(cropped)_(2024).jpg), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Displayed in monochrome with a reaction sticker and invented caption.
- Dragon, dragon face, detective and crying-face SVGs: Twitter Twemoji contributors, [source](https://github.com/twitter/twemoji/tree/master/assets/svg), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Displayed at different sizes as editorial illustrations; these are not official project logos.
- [OWASP Precogly project listing](https://owasp.org/projects/precogly) verifies the project name. [OWASP Threat Dragon](https://owasp.org/www-project-threat-dragon/) is an alternative threat-modeling tool.

The system graphics are original editable SVG diagrams. Layout takes inspiration from spacious diagram canvases and direct manipulation tools, without copying tldraw assets or implying endorsement.
