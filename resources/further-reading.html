Further reading

Start with access control, then apply the four questions to the shop. The remaining references help investigate particular questions that arise.

  • PortSwigger: access control — identity, permissions and practical training labs.
  • OWASP API1:2023 — Broken Object Level Authorization — authorization for a requested resource.
  • OWASP API5:2023 — Broken Function Level Authorization — permission to perform an operation.
  • OWASP Threat Modeling Cheat Sheet — the four-question approach, decomposition and review.
  • Threat Modeling Manifesto — values and principles for useful modeling.
  • Precogly documentation and the source used for this bundle — distinguish the version in this repository from later upstream behavior.
  • Martin Osborne: An Introduction to Game Theory — strategic-form games, best responses and dominance.
  • FIRST CVSS, FIRST EPSS and CISA Known Exploited Vulnerabilities — different inputs to vulnerability prioritization; combine relevant evidence with local exposure and consequences.
  • OWASP Threat Dragon and Microsoft Threat Modeling Tool — alternative tools to explore.

A diagram describes relationships. A threat model adds the reasoning about harm, controls and validation. Tool choice does not replace that reasoning.
