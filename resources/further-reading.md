# Further reading

Start with access control, then apply the four questions to the shop. The remaining references help investigate particular questions that arise.

- [PortSwigger: access control](https://portswigger.net/web-security/access-control) — identity, permissions and practical training labs.
- [OWASP API1:2023 — Broken Object Level Authorization](https://owasp.org/API-Security/editions/2023/en/0xa1-broken-object-level-authorization/) — authorization for a requested resource.
- [OWASP API5:2023 — Broken Function Level Authorization](https://owasp.org/API-Security/editions/2023/en/0xa5-broken-function-level-authorization/) — permission to perform an operation.
- [OWASP Threat Modeling Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Threat_Modeling_Cheat_Sheet.html) — the four-question approach, decomposition and review.
- [Threat Modeling Manifesto](https://www.threatmodelingmanifesto.org/) — values and principles for useful modeling.
- [Precogly documentation](https://precogly.github.io/precogly/) and [the source used for this bundle](https://github.com/precogly/precogly/tree/775a32647263ed7f25e1515fe6df7a8828812e1c) — distinguish the version in this repository from later upstream behavior.
- [Martin Osborne: An Introduction to Game Theory](https://www.economics.utoronto.ca/osborne/igt/) — strategic-form games, best responses and dominance.
- [FIRST CVSS](https://www.first.org/cvss/), [FIRST EPSS](https://www.first.org/epss/) and [CISA Known Exploited Vulnerabilities](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) — different inputs to vulnerability prioritization; combine relevant evidence with local exposure and consequences.
- [OWASP Threat Dragon](https://owasp.org/www-project-threat-dragon/) and [Microsoft Threat Modeling Tool](https://learn.microsoft.com/en-us/azure/security/develop/threat-modeling-tool) — alternative tools to explore.

A diagram describes relationships. A threat model adds the reasoning about harm, controls and validation. Tool choice does not replace that reasoning.
